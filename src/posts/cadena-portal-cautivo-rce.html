Resumen

el daemon de portal cautivo es el punto de acceso autenticado (captive portal) usado masivamente en la distribucion de firmware. El servidor RADIUS parsea la respuesta EAP-Identity del cliente antes de cualquier autenticación; ese valor viaja como variable de entorno al script de arranque de sesión el script de alta de sesion, que lo evalúa como código shell. Un cliente que conecta y envía una identidad con caracteres de shell puede lograr la ejecución de comandos en el daemon.

El análisis fue código-primero sobre el release actual del árbol sin .git: desde la entrada de red (EAP-Response/Identity) hasta el sink de shell, con cada eslabón verificado y la reproducción en el build nativo bajo ASAN.

Ficha técnica

Ficha técnica. Target: el daemon de portal cautivo (servidor RADIUS/captive portal, la distribucion de firmware). Clase: OS command injection — CWE-78. Acceso: Pre-auth, 0 interacción (EAP-Response/Identity). Cadena: el modulo de portal cautivo:790-845 → USER_NAME → el script de alta de sesion → eval. Impacto: ejecución de comandos como administrador del daemon (build uid del proceso). Alcance: WLAN local del AP — no internet-facing directo. Fix: Sin CVE asignado ni parche conocido al cierre.
