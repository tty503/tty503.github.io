Resumen. Autopsia de dos componentes con hallazgos de impacto limitado: la biblioteca cliente del protocolo de streaming y el servidor HTTP minimo. la biblioteca cliente del protocolo de streaming: OOB read CWE-125 en el decode AMF3 (info-leak acotado, sin escalada a escritura). el servidor HTTP minimo: command injection CWE-78 en el generador de el gestor de credenciales (sprintf+system) — pero solo alcanzable por línea de comandos local. Lección: la gravedad la define el encadenamiento + el despliegue real, no el tipo de bug aislado.

Resumen

Análisis forense de dos piezas clásicas del stack embebido. En la biblioteca cliente del protocolo de streaming (RTMP client library), el decoder de AMF3 lee fuera de límites al procesar un tipo de dato mal formado declarado con longitud mayor al payload; el efecto medido es una lectura de memoria no inicializada/acotada, encuadrable solo como fuga de información sin control de flujo.

En el servidor HTTP minimo, el comando que regenera el gestor de credenciales concatena entradas con sprintf y lo pasa a system: inyección de comandos directa, pero el único punto de entrada es la CLI local del administrador — no la red.

Ficha técnica. Hallazgo A: la biblioteca cliente del protocolo de streaming — OOB read en decode AMF3 · CWE-125. Efecto A: Info-leak de lectura acotada, sin escritura (LOW). Lección: Severidad = cadena + despliegue; no el bug suelto.
