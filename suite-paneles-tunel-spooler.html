Suite de scripting servers: el panel web de administracion del servidor, el panel web de administracion restringida, el daemon de tunel L2TP/IPsec y el spooler de impresion

Cuatro sinks de inyección en la familia miniserv + L2TP + el spooler de impresion, y el bypass de confianza X-SSL-Client-* con su alcance real: tres prerrequisitos que no son default.

2026-09-0220 minVulnerability Research

Resumen. Barrido de la suite de acceso web clásica del server de red: 4 sinks de command injection (CWE-78) distribuidos en el panel web de administracion del servidor, el panel web de administracion restringida, el daemon de tunel L2TP/IPsec y el spooler de impresion. Trust-bypass condicional: cabeceras X-SSL-Client-* solo se respetan si trust_real_ip=1 + proxy trusted + DN exacto — no es un bypass de confianza default. Sinks: cpan/el CGI de administracion:45 (root post-auth), el panel web de administracion restringida el CGI de administracion + el CGI de administracion, el daemon de tunel L2TP/IPsec L2TP→ip-up, el spooler de impresion la herramienta de configuracion de impresorasrip. Ninguno es initial-access pre-auth: todos quedan como eslabones post-auth para composición con una primitiva de acceso.

Resumen

Auditoría de la suite completa del servidor de red clásico: el panel web de administracion del servidor/el panel web de administracion restringida (panel de administración web), el daemon de tunel L2TP/IPsec (túnel L2TP/IPsec) y el spooler de impresion (impresoras). El barrido estático encontró cuatro puntos donde una entrada influenciable aterriza en system/shell sin sanitizar, todos documentados con archivo:línea y prueba de inyección.

La revisión adversarial verificó además el mecanismo de confianza por cabeceras X-SSL-Client-Cert-DN: la fe en esas cabeceras exige configuración específica (proxy trusted y trust_real_ip=1) — por tanto no cuenta como bypass de autenticación en config default.

Ficha técnica

Ficha técnica. Clase: OS command injection — CWE-78 (4 sinks). el panel web de administracion del servidor: cpan/el CGI de administracion:45 — post-autenticación. el panel web de administracion restringida: ssh/el CGI de administracion y el CGI de administracion — post-auth. el daemon de tunel L2TP/IPsec: L2TP → scripts ip-up al conectar túnel. el spooler de impresion: la herramienta de configuracion de impresorasrip al procesar trabajo de impresión. Trust-bypass: X-SSL-Client-* condicional ( trust_real_ip=1 + proxy + DN). Acceso: Ninguno pre-auth — todos son eslabones post-auth.

Veredicto. No hay initial-access pre-auth aquí. El activo real son los sinks post-auth documentados, reactivables componiéndolos con una primitiva de acceso (una sola pieza de auth-bypass los convierte en cadena completa).
