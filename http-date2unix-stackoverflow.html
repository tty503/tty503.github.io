el servidor HTTP embebido: stack overflow en el conversor de fecha a timestamp (CWE-121)

Un If-Modified-Since de 220 bytes desborda un buffer de 128 y permite tomar control parcial del contador de programa con un descifrado en pila. Disparidad nativo/gdb (+0xC0) documentada y reproducción incluida.

2026-09-0216 minVulnerability Research

Resumen. Stack overflow en el servidor HTTP embebido: la cabecera If-Modified-Since de ~220 bytes desborda un buffer de 128 en el conversor de fecha a timestamp con control parcial de RIP. Sink: file.c:136 — strncpy copia strlen(origen) bytes sin bound. Shellcode decoder XOR en-stack que evita los bytes prohibidos del transporte HTTP; el desplazamiento de RIP en gdb difiere +0xC0 del run nativo (offset calibrado por ensayo). CWE-121 (Stack-based Buffer Overflow). Repro 3/3 con crash ASAN.

Resumen

el servidor HTTP embebido es un servidor HTTP mínimo usado en routers embebidos (incluido como submodulo en el daemon de autenticacion y redireccion). Al servir un recurso estático, convierte la cabecera If-Modified-Since a timestamp Unix con el conversor de fecha a timestamp; la copia a buf[128] usa como límite el propio strlen de la entrada, permitiendo escribir más allá del frame. Con 220 bytes se llega al return address y se desvía el flujo.

Parte del trabajo consistió en entender la restricción del canal de transporte HTTP y calibrar la reproducción entre el modo depurador y la ejecución nativa.

Ficha técnica

Ficha técnica. Target: el servidor HTTP embebido (HTTP server embebido). Clase: Stack buffer overflow — CWE-121. Vector: Cabecera If-Modified-Since ≈ 220 B → buf[128]. Sink: file.c:136 — strncpy sin bound real. Efecto: Control parcial de RIP; crash ASAN reproducible 3/3. Canal: Payload XOR-on-stack evadiendo bytes prohibidos HTTP. Fix: Sin CVE asignado al cierre del análisis.
